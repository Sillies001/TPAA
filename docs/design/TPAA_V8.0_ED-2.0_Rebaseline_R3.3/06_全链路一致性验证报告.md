## 4. Family Applicability 结论

`P1_METRIC_CATALOG.json` v1.14.0 现在机器冻结：

- SNS = RADAR sensor detection/measurement；
- PSV = IRST/EO passive sensor；
- ESM = RWR/ESM emitter sensing；
- DL = DATALINK；
- FUS = FUSION；
- TRK/ID 依赖受治理的 Local Track / Association-Identification product capability，而不是把所有 mission-system 数据视为同一传感器层。

Applicability Gate 应先于 input resolution；字段偶然齐全不能绕过产品层约束。
