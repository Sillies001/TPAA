# ADR-GUI-003：三主题使用统一语义 token，并保持会话内状态

- 状态：`APPROVED_LOCAL`
- 日期：2026-11-06（v33 修订）
- 决策范围：V01～V26 的 Tactical、Graphite、Light 三主题

## 决策

1. 支持 `tactical`、`graphite`、`light` 三个主题，默认 `graphite`。
2. 主题只保存在当前桌面会话内；每次启动恢复 Graphite，不写 localStorage、Cookie、数据库或用户配置。
3. 主题只改变表现，不改变数值、状态、权限、可用性、排序、证据或业务语义。
4. 组件只能引用语义 token，例如背景、表面、边框、正文、弱化文字、强调、成功、警告、失败、焦点；禁止在业务页面散落具体颜色。
5. `N_A`、`INSUFFICIENT`、`INVALID`、`SYSTEM_ERROR` 等状态同时使用中文文本、形状/图标和颜色；禁止只靠颜色区分。
6. 三主题必须覆盖相同的可见焦点、键盘顺序、对比度和高 DPI 行为。普通文本目标为 WCAG 2.1 AA；图表线、选区和焦点环必须在各自背景上可辨认。
7. V25 负责预览与切换，但主题切换动作不得触发后端写操作或审计业务变更。

## 理由

冻结 Demo 明确要求每次打开默认深色 Graphite，且主题只影响界面。会话内状态避免把浏览器存储引入受治理桌面应用，也避免不同角色或用户之间泄漏偏好。语义 token 保证三主题在后续页面快速扩展时仍保持状态含义和可访问性一致。

## 验收

- 26 个视图在三主题下各有参考截图，共 78 个组合；
- 同一视图切换主题后业务 DOM/DTO 标识与数值完全一致；
- 关闭并重新启动后恢复 Graphite；
- 键盘焦点、禁用、选择、告警和错误状态不因主题丢失；
- 不存在 localStorage、Cookie 或后端 theme preference 写入。
